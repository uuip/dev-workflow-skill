Use skill `superpowers:test-driven-development`.

本轮属于 TDD 实现阶段。

输入：
1. 已确认的开发任务
2. 已确认的编码前修改计划
3. 已确认的失败测试清单

要求：
1. 先写失败测试。
2. 运行测试，确认失败原因正确。
3. 不允许在失败测试前写生产代码。
4. 写最小实现让测试通过。
5. 运行测试确认通过。
6. 只在测试通过后做必要清理。
7. 不增加计划外功能。
8. 不重构无关代码。
9. 不新增无关抽象。

输出：
1. 新增或修改的测试
2. 测试失败结果
3. 实现改动
4. 测试通过结果
5. 是否有必要清理
6. 下一步是否进入集成测试阶段
